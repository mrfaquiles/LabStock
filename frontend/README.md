# LabStock: frontend

Interface em Vue 3 e Vuetify do sistema LabStock.

A instalação, as regras do sistema e os passos para produção estão no [README principal](../README.md).

```bash
npm install
npm run dev
```

O endereço da API vem de `VITE_API_URL` (veja `.env.example`). Sem essa variável, o sistema usa `http://127.0.0.1:8000/api/`.
